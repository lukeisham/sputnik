## Purpose
Add four user-facing interaction features — multi-style box frames in the editor auto-complete, copy-to-clipboard in the Studio, library search, and tap-to-edit canvas cells — improving daily editing flow without touching the conversion pipeline.

## Success Condition
- Typing `╔═` in the editor auto-complete offers a double-line box frame; `╭─` offers a rounded-corner frame; `+--` still offers the existing ASCII frame.
- The "Copy" button in the Studio action bar copies the entire canvas text to the system pasteboard; pasting into a monospace text editor produces the correct layout.
- Typing in the library search field filters the displayed art in real time; clearing the field restores all entries.
- Tapping a cell in the canvas (`MonoGridView`) highlights it and replaces its character with the character typed into the "Insert character" field.
- `swift build` (all targets) produces zero errors and zero warnings.

## Steps

- [ ] C1. **Multi-style box frames in `ASCIIArtLanguageProvider.analyse` (3.3)**
   What: In `ASCIIArtLanguageProvider.analyse(text:cursorPos:)`, extend the existing branch that checks `currentLine.hasSuffix("┌─")`:
   - `currentLine.hasSuffix("╔═")` → payload frame using `╔══════╗\n║      ║\n╚══════╝`, preview `╔══════╗`
   - `currentLine.hasSuffix("╭─")` → payload frame using `╭──────╮\n│      │\n╰──────╯`, preview `╭──────╮`
   - Keep the existing `+--` (ASCII) and `┌─` (single-line) branches unchanged.
   All four branches return a `BlockCompletion.Payload`; no new types are needed.
   Why: The editor currently offers only one box style. Users composing ASCII diagrams need at least single, double, rounded, and ASCII-compatible variants without switching apps.

- [ ] C2. **Copy-to-clipboard button in the Studio action bar (10)**
   What: In `ASCIIStudioView`, add `Button("Copy") { copyToClipboard() }` to the existing `actionBar` HStack, positioned next to "Insert at Cursor". Implement:
   ```swift
   private func copyToClipboard() {
       let text = imageEditor.renderAsText()
       NSPasteboard.general.clearContents()
       NSPasteboard.general.setString(text, forType: .string)
   }
   ```
   Add `.help("Copy ASCII art to clipboard")`.
   Why: The most common exit path from the Studio is pasting the art into the editor or another app. The current workflow requires Save → open file → copy text — three extra steps.

- [ ] C3. **Library search TextField above the category picker (10)**
   What: In the `libraryTab` section of `ASCIIStudioView`:
   1. Add `@State private var librarySearchQuery: String = ""`.
   2. Add `TextField("Search library…", text: $librarySearchQuery)` above the category `Picker`.
   3. Add a computed property `filteredLibraryItems: [ASCIIArtRecord]` that filters `libraryItems` by `librarySearchQuery` (case-insensitive `localizedCaseInsensitiveContains` on `record.title` and `record.tags`). Return `libraryItems` unfiltered when `librarySearchQuery.isEmpty`.
   4. Replace the existing `ForEach(libraryItems)` with `ForEach(filteredLibraryItems)`.
   5. When `librarySearchQuery` is non-empty, hide or disable the category `Picker` (search overrides category).
   Why: The library grows as users add entries. Category browsing alone becomes unwieldy at more than ~30 items; search is the standard escape hatch.

- [ ] C4. **Tap-to-edit canvas cells via `MonoGridView` (10)**
   What:
   1. In `ASCIIImageEditor`, add:
      - `@Published var selectedCell: (row: Int, col: Int)? = nil`
      - `func selectCell(row: Int, col: Int)` — sets `selectedCell`
      - `func replaceSelectedCell(with char: Character)` — replaces `grid[row][col]` and registers undo via the existing undo-registration pattern
   2. Create `MonoGridView: NSViewRepresentable` in a new file `10 ASCII Studio/Sources/MonoGridView.swift`. It wraps a custom `NSView` that:
      - Draws each cell as a fixed-width monospaced glyph (cell size derived from `NSFont.monospacedSystemFont` metrics)
      - On `mouseDown(with:)`, converts the click point to (row, col) and calls `ASCIIImageEditor.selectCell(row:col:)`
      - Highlights the selected cell with a tinted background rectangle (use `NSColor.selectedTextBackgroundColor.withAlphaComponent(0.4)`)
   3. In `ASCIIStudioView`, replace the current `editableCanvas` placeholder with `MonoGridView(editor: imageEditor)`. Add a `TextField("Character", text: $insertChar)` limited to 1 character and an "Apply" `Button` that calls `imageEditor.replaceSelectedCell(with:)`.
   Why: The "editable canvas" tab currently has a stub `onTapGesture` that calls nothing. Tapping a cell and replacing its character is the minimum viable canvas interaction.

## Risks and Constraints
- **SR-1 (C4):** `MonoGridView` is new and lives entirely within module 10; it references `ASCIIImageEditor` only via the module's own types — no cross-module import.
- **SR-4 (C4):** Cell replacement is in-memory and synchronous; no background dispatch needed. `NSView` drawing is on the main thread.
- **SW-3 (C4):** `MonoGridView` uses `NSViewRepresentable` because SwiftUI `Canvas` cannot handle per-character click hit-testing at the required granularity without significant complexity. Document this at the call site.
- **`insertChar` (C4):** Bind to a `@State private var insertChar: String = " "`. In the TextField, use `.onChange(of: insertChar) { if $0.count > 1 { insertChar = String($0.suffix(1)) } }` to enforce the single-character limit.
- **C3 and category picker:** when `librarySearchQuery` is non-empty, the category picker should be clearly disabled (`.disabled(!librarySearchQuery.isEmpty)`) rather than hidden, so users know it still exists.
